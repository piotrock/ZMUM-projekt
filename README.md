# ZMUM-projekt
Projekt semestralny z przedmiotu Zaawansowane Metody Uczenia Maszynowego

## Opis problemu
Projekt dotyczy porównania technik redukcji wymiarowości w kontekście analizy i wizualizacji danych wysokowymiarowych. W szczególności badamy klasyczne metody liniowe, takie jak PCA oraz MDS, a także nowoczesne algorytmy nieliniowe, takie jak t-SNE i UMAP. Dodatkowo uwzględniamy metodę nadzorowaną LDA, aby porównać jej skuteczność względem metod nienadzorowanych.

## Cel projektu
Celem projektu jest zbadanie, w jakim stopniu redukcja wymiarowości wpływa na jakość klasyfikacji oraz czy różne metody zachowują strukturę danych w sposób użyteczny dla modeli uczących się. Analizujemy zarówno jakość wizualizacji (np. separowalność klas), jak i wpływ na metryki klasyfikacyjne przy dużej liczbie cech.
